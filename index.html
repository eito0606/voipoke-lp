02 // EXPERIENCE

指であやつる 耳がよろこぶ

PROCESS // 03 STEPS

こえを、あやつる時代

声優のこえを点として配置し、リスナーのまわりを移動。 左右の耳に届くタイミングと音量、周波数のわずかな差が、脳に「方向」を伝えます。
ドラッグはそのまま、こえの座標になります。

  • 01指の位置から3次元座標を検出touch → vec3
  • 02HRTFで左右耳の波形を合成binaural mix
  • 03距離・反響・方向感をつくるenv node
※ イヤホン推奨 ─ スピーカーだと、立体感はうすれます
